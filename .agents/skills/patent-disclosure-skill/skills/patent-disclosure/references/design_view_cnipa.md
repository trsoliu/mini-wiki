# 外观视图口径（审查指南 4.2）

交底出图与申请核查用**同一清单**。依据：《专利审查指南》（2023）第一部分第三章 4.2；电子申请图幅见国知局客服口径（以客户端当期校验为准）。

本文在交底包与申请包各有一份，**须保持同文**。改一处须同步另一处。

## 选哪几张（非默认六视）

- 立体产品：要点涉及六个面才交六面正投影；只涉及部分面则交所涉面正投影，其余面可正投影或立体图。
- 平面产品：一面或两面正投影。
- 使用时看不到的面、相同或对称的面：写入 `omitted_views`，简要说明写原因（如「后视图与主视图对称，省略后视图」）。**禁止**为省略面或未见背面/底面编图。
- 要点落面没有源图 → `uncertain`，与故意省略分开。
- 交底、申请都按落面出图/核查，**不默补六张**。

## 视图名称（标在图外正下方，不烧进像素）

正投影六面：**主视图、后视图、左视图、右视图、俯视图、仰视图**。立体图称 **立体图**。  
`claimed_faces` / `covers` / Markdown 与 Word **图题**用全称。主视图取使用时朝向消费者的面，或最能反映整体的面。  
成套：`套件 4 主视图`；相似设计：`设计 1 主视图`。图内不得画图号、视图名。

## 虚线范围（先锁再画）

主张保护的轮廓用**实线**。不主张的环境或边界若画出，一律**虚线**，且各视同一部位线型必须相同。禁止把虚线当装饰纹理。点划线仍不得表达外形。

出线稿前写入 AppearanceSchema `line_scope`：

- `claimed`：实线部位（主张）
- `unclaimed`：虚线部位（不主张，可空 = 全部可见轮廓为实线）
- `by_view`：各视复核，须与上表同一口径

无 `line_scope` 不得当已锁定。改锁定表后再改图，不要各视各画一套范围。

## 线稿（4.2.2）

- 正投影关系正确；各视比例一致；方向不颠倒。
- 粗细均匀的实线表达外形。**禁止**用阴影线、指示线、中心线、尺寸线、点划线表达外形。
- 计算机绘制须清晰。画布按电子申请常见限制：**JPEG、不超过 150mm×220mm、72–300 DPI**（生成时对准；不要先画草稿再另包加工）。
- 已有线稿未过本清单 → **不得** `existing_lineart`，必须重画。`quality` 不得超过 69。

## 实拍（4.2.3）

合格 `photo_clean`：清晰、单一背景、与背景有明度差、通常正投影、避免强光/反光/阴影/倒影。  
透视棚拍、包装场景 → `photo_scene`，只可作图生图参考，不得当合格正投影入文。  
CAD / STEP 投影 → `kind: cad`，只作参考，**不入文**、不当六视图。

## 交底入文 vs 递交集合

交底可同时嵌干净实拍与线稿（给人对照）。递交同一件外观**不得图片与照片混用**：申请文件选定全线稿或全实拍，记在 `视图选择.md`。

## 申请文件

用本清单核查：落面覆盖、虚线范围、省略原因用语、图照片不混、投影关系、图幅/DPI。  
**不改交底原图**（不裁边、不缩放、不改 DPI、不跑升格脚本改像素）。可把入文图**原样复制**到申请产出 `figures/` 便于 Word 引用。  
漏视、虚线不一致、新事项风险写入 **`视图检查清单.md`**，并摘要进 `问题清单.md`。不加工像素、不默补假面、不写入简要说明正文。
