# 专利布局 · 保护型 1+N（交底旁路 · 总则）

本目录是交底包**旁路**，不是第三种专利类型，也不是专利地图。首篇交底仍按 Step 1–8 先写完（挖点/查新不改）。

**只做保护型**：护自己的核心（1 件核心 + N 件外围）。不做制衡型围别人、地毯式、全球组合。本趟只出**中国交底**。

**先 `Read` 本文件，再按阶段只读一份：**

| 阶段 | 再读 |
|------|------|
| 用户已答应做保护型 1+N，尚未分解 | `decompose.md` |
| 分解已落盘 | `design_around.md` |
| 突围已落盘 | `matrix.md` |
| 矩阵已落盘 | `plan.md`（family.yaml + 专利布局.md） |
| 立项说明已出、立项后弱校验 | `score.md` |
| 用户确认本趟节点 | `dispatch.md` |

点名「专利布局 / 专利围栏 / 族树」可强开，但仍必须跑完分解 → 突围 → 矩阵，再立项。

## 做什么

1. 首篇交付后，把「要不要做保护型 1+N」写进 **`## 交付后请确认` 第 3 条**（`prompts/delivery_confirm.md`）：核心收窄 + 场景/改进/上下游外围。不评高价值分再问。未答应则结束旁路。  
2. 技术分解 → 突围路径（全面覆盖/等同列表）→ 技术功效矩阵（手段×功效；未检索不得标空白）→ 立项 1+N：`family.yaml` 供校验与分件，`专利布局.md` 由模型直接写成给人看的说明稿。  
3. 立项后弱校验（≥1 外围、材料够）；把作答表与分件门槛**回写**说明稿 `## 立项校验`。过门槛则对话**推荐**分件；未过门槛则**不推荐**本趟拆多件（临界可只写仍有落点且材料够的节点）。未过则建议只留首篇，不强行开写。不是高价值达标认定。  
4. 用户确认节点后分件写交底：每件自己查新；核心瘦身另存；外围按 `scenario|improve|chain` 写。不自动申请/案卷。

## 禁止

- 先打分再决定问不问；把本旁路叫成资产评估或国知局高价值统计达标  
- 评分未决打正分；编造营收、同族、金奖、质押  
- 制衡型围别人；本趟出海外同族/多局申请  
- 矩阵未检索就标「空白/蓝海」；`dense` 或 `material_ok=false` 仍 `write_this_round`  
- 外围复述核心独权；核心独权下位单独立项  
- 旁路再走「3–5 点融合成一篇」  
- 本趟核心成稿 >2 或外围成稿 >3  
- 对每件自动跑申请四件套或案卷
