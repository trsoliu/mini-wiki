# 交底书生成前摘要预览（Step 6）

## 目的

在输出完整长文前降低返工：先展示结构化摘要，请用户 **确认 / 调整方向**。

若用户明确要求跳过预览，可直接进入**当前类型**目录下的 `disclosure_builder.md` 生成全文。

## 类型路由（摘要口径）

| 专利类型 | 成文入口 | 摘要侧重点 |
|----------|----------|------------|
| 发明（默认） | `invention/disclosure_builder.md` | 问题 → 模块/步骤 → **D1 与区别特征 Fk** |
| 实用新型 | `utility_model/disclosure_builder.md` | 结构问题 → 关键部件/连接 → **D1 与区别特征 Fk**（比部件与连接关系） |
| 外观设计 | `design/disclosure_builder.md` | 产品用途 → 设计要点 → 视图覆盖 → 与在先外观差异 |

材料明显更偏结构/外观且当前仍为默认发明时，按 `intake.md` **反问是否改类型**（本步宜问一次）。

## 摘要应包含（按类型裁剪）

**共通**

- 选定名称（工作标题 / 产品名）
- 专利类型（含「发明（默认）」字样若适用）
- **D1 与区别特征**：过 / 带疑点过时，点名最接近的一篇（公开号 + 标题 + 一句选定理由），并逐条列出 **F1…Fn**（每条用完整特征句，不要只报编号）。编号与口径须与落盘比对表**一致**，**不要**在预览里另起一套说法。有 D2 补行则各用一句说明「哪条特征、D2 可能被组合」（用中文构造名，可括注 Fk）。无检索则标明待查新；外观改为与在先设计的造型/图案/色彩要点差异（可不用 Fk 编号）。
- **门禁三态**（见 `prior_art_search.md`「门禁」）：**三态都出预览**。带疑点过时摘要里**单独几句**写清不确定处及仍选该篇的理由。**不过**时预览**开头**写明「本次未钉住最接近对比文件，创造性论述已降级」；列出相对材料/常规做法的 Fk，**不要**编造 D1 公开号。该拆案则建议拆，仍给出本篇摘要。不要把疑点藏到成文之后。

**发明另含**

- 解决的技术问题 1–3 条  
- 核心创新模块或步骤 3–6 条  

**实用新型另含**

- 结构问题 1–3 条  
- 关键部件与连接关系 3–6 条（可对照 StructureSchema）  
- 附图是否齐备（对照 **`figure_plan`**：拟入文图序、kind、**图际关联**；主题若调整须说明将重评清单）  

**外观另含**

- 设计要点 3–6 条（对照 AppearanceSchema）  
- 已有视图清单（对照 **`figure_plan`**）；缺视图须列出  

## 可选确认语

**发明：**

```
以上方向是否确认？确认后将按发明模版输出完整技术交底书，含 mermaid 系统框图与流程图（定稿时将转为 PNG 并同时交付 .md 与 .docx）。
```

**实用新型：**

```
以上方向是否确认？确认后将按实用新型模版输出交底书（结构主线 + 附图；定稿交付带时间戳的 .md，建议同时 .docx）。
```

**外观设计：**

```
以上方向是否确认？确认后将按外观说明底稿输出（设计要点 + 视图；定稿交付带时间戳的 .md，配图齐全）。
```

## 禁止写入

摘要 Markdown **末尾不得**追加技能仓库名、`examples/` 路径、「教学示例」「虚构」「不构成法律承诺」等脚注（与各类型 `disclosure_builder.md` 对定稿的要求一致）。
