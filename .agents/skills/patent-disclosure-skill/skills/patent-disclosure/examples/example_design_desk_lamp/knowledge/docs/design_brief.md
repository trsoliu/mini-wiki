# 折臂台灯外观设计（虚构）

## 产品

一种台式阅读灯，整体由**圆盘底座**、**折臂**与**梯形灯罩**组成。

## 设计要点（外观）

1. **整体造型**：自底座向上折臂连接梯形半透明灯罩，侧视呈「L→折线→罩」轮廓。  
2. **底座**：正圆盘，中央小圆凸台。  
3. **灯罩**：圆角梯形，暖色半透明感（示意图用黄色块表示）。  
4. **视图**：`assets/` 已放桌面场景实拍、灯臂/关节局部与包装盒图。交底按要点落面收正投影（非默认六视）；相同/对称/无要点面写入 `omitted_views`。

## 边界

本案仅保护**外观美感表达**；内部电路、散热卡扣等结构改进应另案实用新型 / 发明，勿写入外观设计要点。
