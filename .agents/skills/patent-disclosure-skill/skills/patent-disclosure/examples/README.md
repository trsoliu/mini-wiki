# 交底示例案件

本包可随仓库提交的演练材料。解读 / 审查答复示例在各自技能包。

| 路径 | 类型 | 说明 |
|------|------|------|
| `example_batch_job_scheduler/` | 发明 | 虚构「批任务调度」；扫 `knowledge/` |
| `example_utility_model_ev_powertrain/` | 实用新型 | 电驱桥壳体教学 brief；展台实拍作参考；文生图出结构线稿 |
| `example_design_desk_lamp/` | 外观设计 | 折臂台灯教学 brief；国内媒体实拍 |

扫描路径请用本包前缀，例如：

`skills/patent-disclosure/examples/example_batch_job_scheduler/knowledge/`

产出仍写到仓库根 `outputs/{案件标识}/`。
