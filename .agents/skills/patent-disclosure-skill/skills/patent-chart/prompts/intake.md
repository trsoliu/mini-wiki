# 对照表 intake

先在对话里锁定三件套。够用就直接落盘再分析；不够就按题问，一题一问，等用户回。不编造材料。

一进技能、开始收集前，先建本轮会话目录（时间戳精确到秒，同一秒冲突则加 `-2`）。后面的 `intake.json` 和对照表都写进这一层，不覆盖其他轮次：

```bash
python skills/patent-chart/tools/write_intake.py --dir outputs/patent-chart/{案件} --alloc
```

记下 stdout 的 `INTAKE_DIR:` / `INTAKE_SESSION:`（形如 `outputs/patent-chart/{案件}/20260929-232015/`）。同一对话里要做另一套对照，再 `--alloc` 一次。

## 三件套

| 项 | 要有什么 |
|----|----------|
| 对照类型 `scene` | 见下表，未说则问，不要默认成 FTO/侵权 |
| 左列 | 已公开：专利号。未公开：方案文件或权要原文 |
| 右列 | 至少一份对照。可一次列多份 |

| 用户说法 | `scene` | 右列要什么 |
|----------|---------|------------|
| 无效对照 / 无效初筛 | `invalidity` | 对照专利号（可多个） |
| FTO / 自由实施 | `fto` | 产品名称 + 产品链接或说明书/截图 |
| 侵权 / EoU / 证据使用 | `infringement` | 同上 |
| SEP / 标准必要 | `sep` | 标准号或标准文件（可多个） |
| 可专利性 / 交底对照 / 未说场景 | `patentability` | 对照专利号（可多个） |

产品名称只作列名，**不是**专利检索词。有产品链接就抓该页当原文，不要只凭名称猜结构。  
用户已指定全部对照对象 → 不要为凑数去检索。可专利性/无效且用户明说「对比文件未定、请补搜」→ 记 `search_fill: true`，右列可暂空。FTO/侵权不能靠补搜代替产品名称和链接/资料。默认连从权一起拆。

三件套不齐时只提问。已有同号 `claim_features.json` 且用户未要求重读 → 跳过解读。否则在 `INTAKE_OK:1` 之后才派解读包。

## 对话里已经够用

不要再提问。把已知字段写成临时 JSON，写入**本轮已 alloc 的会话目录**：

```bash
python skills/patent-chart/tools/write_intake.py --into {INTAKE_DIR} --json {临时json}
```

看到 `INTAKE_OK:1` 后记下 `INTAKE_DIR:`，**这时才**继续解读 / 检索 / 填格。导出用同一个目录：

```bash
python skills/patent-chart/tools/emit_chart.py --json {INTAKE_DIR}/_payload.json --into {INTAKE_DIR}
```

## 不够就 ASK（一题一问）

缺哪件问哪件，已经有的跳过。问完停下来等回复，不要连发三问，不要假装已经收齐。

**第一问 · 对照类型**（只有类型不清才问）。给选项：

1. 可专利性：和已有公开比，看方案新不新  
2. 无效对照：用在先公开挑战这项专利  
3. FTO 初筛：产品上市前排查他人专利  
4. 侵权对照：产品是否落入权利要求  
5. 标准必要：专利与行业标准是否对应  

用户回序号或短词即可。有选项卡工具时这一题可用选项卡。

**第二问 · 左列**（只有左列不清才问）。按已公开 / 未公开二选一：

- 已公开：只要专利号  
- 未公开：请给出方案文件，或直接粘贴权利要求原文  

**第三问 · 右列**（只有右列不够才问）。说明可以一次给多份：

- 可专利性 / 无效：对照专利号，多个就换行列出；也可以说「没有指定，请按权要补搜」  
- FTO / 侵权：每件产品一行「名称 + 链接」，没有链接再补说明书或截图  
- 标准必要：标准号或标准文件路径  

材料仍不足（例如侵权只有产品名、没有链接也没有文件；可专利性还没说清对照号或是否补搜）→ 停在这一问，点名缺什么。**不要**派解读、**不要**检索、**不要**填格。

## 收齐后落盘

检查通过才写 `intake.json`（`write_intake.py` 不完整会 `INTAKE_OK:0` 且不写文件）。本轮只有一份：

`outputs/patent-chart/{案件}/{YYYYMMDD-HHMMSS}/intake.json`

目录在**开始对话时** `--alloc` 建好；json 在收齐后才写入该目录。不要用 `--dir --json` 再新建一层，以免时间戳变成「开始分析」而不是「开始对话」。

不要打开本机网页表单，不要让用户下载 JSON，不要做文件监听。
