# 政策简报 · 检索与官网抓取

前置：已 Read `guardrails.md`、`intake.md`。  
**先 `Read` `skills/patent-exam-policy/references/sources.yaml`。**

## 目标

收集 **近期**（默认近 12 个月）与**交底写法**、**申请书式**相关的权威口径，尤其：

1. **审查工具**：国知局智能审查 / 大模型检索等公开口径  
2. **申请客体与指南**：AI/大数据/算法特征、充分公开、创造性、伦理（五条一款）  
3. **程序通识**：专利法 / 实施细则、创造性评价、双申等可能影响交底或申请书式的规则  
4. **实用新型**：明显创造性、保护点与结构可实施（映射表有主题，种子必须对上）  
5. **外观设计**：局部外观、GUI / 图形用户界面、相似外观、明显区别、视图与简要说明  

每条进入简报的观点必须能对应到 **可点击的准确 URL**。

## 信源分层（打开顺序）

| 层 | 打开谁 | 写入简报 | 可否单独支撑改技能 |
|----|--------|----------|-------------------|
| A | `columns` + `documents`（国知局栏目、专利法 / 实施细则 / 指南正文、人大修改决定、国务院公报转载） | 主表 | 仅旁路，且默认只对应交底包 |
| B | `layer_b`（新闻发布会 / 图文直播、司法部·国知局答记者问、复审无效典型案例、最高法知产法庭） | 主表须标 B；司法与案例**默认另议** | **否**（不得当改技能唯一依据） |
| 另议 | 各地保护中心预审须知、代办处地址类公告、仅影响预审格式的材料 | 只进「另议」 | 否 |

B 源规则：国知局新闻发布会、条法司 / 审查业务管理部答记者问，须官网或新华社转载且能对到原话。  
最高法知产法庭的指导性案例、司法解释、年度白皮书：**司法口径 ≠ 审查指南**，对照可以，不要写成审查授权条件。  
保护中心预审：只影响预审格式时进另议，**不要**写成全国交底硬性要求。

## 证据等级

| 等级 | 定义 | 写入简报主表 | 可否作为改技能依据 |
|------|------|--------------|-------------------|
| A | 局令 / 法律 / 实施细则 /《专利审查指南》正文 / 官网公告 | 是 | 仅旁路，且默认只对应交底包 |
| B | 政策解读、负责人答问、新闻发布会通稿、典型案例、司法解释（可核 URL） | 是（须注明解读 / 司法 / 案例非条文） | 不得单独支撑 |
| C | 媒体/律所二次解读 | 只可「背景」，标「待官网复核」 | 否 |

域名优先级：`cnipa.gov.cn`、`npc.gov.cn`、`gov.cn` 公报、`moj.gov.cn` 答问、`ipc.court.gov.cn` / `court.gov.cn`。C 源只作线索。

## 检索动作（须实际执行）

1. **打开 A 栏目**：对 `sources.yaml` 的 `columns` 每个 `url` 用 WebFetch / `curl` 读列表（标题、发布/施行日）。记录**最终打开的地址**。  
2. **打开 A 文本锚点**：`documents` 用于核现行有效全文与施行日；时间窗内有新修订则跟进栏目里的新链接，不要死盯旧深链。  
3. **打开 B 栏目**：`layer_b` 每趟至少扫列表标题；与交底写法或申请书式相关的再点正文。司法 / 案例默认进另议。  
4. **`WebSearch`** 补时间窗内新稿（可加当前年与上一年），关键词见 `search_hints`。**实用新型明显创造性、局部外观、GUI、相似外观、实施细则、司法解释、典型案例**不得漏搜。命中后同样打开正文。  
5. **施行日历**：在 `col99` 部门规章（及公告里的局令）列出「已公布、施行日未到」的条目；已公布且已施行的新局令也入日历，并标明「已可作为交底硬性要求」。第 84 号局令是样板（见 `calendar_examples`）。  
6. 页面被 WAF 挡住：记下 URL 与「抓取失败」，**不要**假装读过正文；不要为简报去 import 交底/检索爬虫当查新引擎。  
7. **拒绝**：无日期或明显过期且已被新局令替代、又无法说明仍有效的孤证；论坛帖、营销软文。不要为凑数去堆易 404 的深链。

默认不打开：WIPO / USPTO / EPO、需登录检索站。不是本趟用户点名的域外规则不要当种子。

## 轨道标签（每条情报必标）

| 标签 | 含义 |
|------|------|
| `审查工具` | AI/大模型作为审查辅助 |
| `申请客体` | AI/算法相关发明的授权与撰写规则 |
| `程序通识` | 专利法、实施细则、创造性、双申等通用规则 |
| `实用新型` | 明显创造性、结构保护点、初步审查口径 |
| `外观设计` | 局部外观、GUI、相似外观、明显区别、视图 / 简要说明 |

另标 **影响面**：`交底` / `申请` / `解读` / `答复` / `检索` / `路由` / `仅背景`（可多值）。简报主文写交底 + 申请书式；解读 / 答复 / 检索、以及申请程序项进「另议」。

主题须能对上 `topic_prompt_map.md`：**交底表**（实用新型明显创造性、局部外观 / GUI 等）与**申请表**（权要书式、摘要、附图、外观视图）。**禁止**再出现「映射表有、本趟源表完全没扫」。申请程序项不对两表：进另议。

## 对照本稿（有则做）

工作区若有交底定稿（`outputs/` 下 `*_YYYYMMDDHHmmss.md` 或用户点名的稿），`Read` 最新一份，把 S* 与章节/保护点对上，供简报「对本稿」列使用。无稿则该列填「无本稿」。  
若有申请产出（`outputs/patent-application/`），第 4 节「对本稿」可对照；无则填「无本稿」。
