## 人工对照

对每一项权利要求，在说明书里点到：

| 权项 | 发明内容 | 具体实施方式 | 附图 |
|------|----------|--------------|------|
| 独权步骤一… | 发明内容独立方案同序 | 第一种实施例按同序走通 | 图 2 框内同义 |
| 从属优选参数 | 「进一步」可点到 | 第一种数值例或表 N | 不强制单独图 |
| 从属分支 | 必要则一句 | 第二种或分支走查 | 不要画进独权主流程 |
| 系统独权模块名 | 发明内容系统方案 | 结合图 1 说明连接 | 图 1 框内同一套名称 |

实用新型：件号在权要、说明书、图上同一张表（`numeral_register.md`）。

## 机器对照

```bash
python skills/patent-application/tools/check_support.py \
  --dir <产出目录>
```

看 `APPLICATION_SUPPORT:`。ERROR 先改权要/说明书/附图 YAML 再交付；WARNING 进问题清单。

脚本核：独权「步骤N」与流程图标签；框图模块名是否出现在说明书与系统权要；附图说明是否点到每张 `图N`；摘要字数与宣传语（`references/promo_terms.yaml`）。语义是否写够仍靠上表，脚本通过不等于充分公开。
