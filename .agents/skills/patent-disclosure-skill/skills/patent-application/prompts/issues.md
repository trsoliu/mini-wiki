# 申请文件 · 问题清单

主文件写完后写 `问题清单.md`。**不要**写入权利要求书、说明书、摘要或附图。

列出已选定写法之外的缺口，例如：保护范围是否过宽、交底歧义的备选、查新未复做、发明人未填、PNG 未生成、公式未转成 OMML、对照表对不上、所述缺少前置、摘要超 300 字。  
抄 `APPLICATION_CLAIMS` / `APPLICATION_NUMERALS` / `APPLICATION_FIG` / `APPLICATION_SUPPORT` 的结果。

不要因此删掉或停写四件套。无额外缺口也仍须落盘清单（可只含机器检查）。

## 对话末尾（强制，与落盘同一条回复）

四件套路径说完之后，**最后**用一小段提醒，不可省略、不可只写「详见问题清单」。

1. 写出 `问题清单.md` 的工作区相对路径（如 `outputs/patent-application/{案件}_{时间戳}/问题清单.md`），明确请先打开该文件再改 Word 或上传。
2. 用短句摘要清单里须人处理的条目（发明人未填、查新未复做、权要备选、PNG/OMML 失败等）。条目多则列要点，不要整文件粘贴。
3. 只有机器检查、没有内容缺口时：仍给出路径，并说明机器通过不等于授权、不等于客户端校验已通过。
4. 未宣称已通过国知局附图审查或电子申请格式校验。
