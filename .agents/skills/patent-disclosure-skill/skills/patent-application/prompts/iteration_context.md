已有申请四件套上继续改时，先读本文，再读 `iteration.md`。不要回到交底挖点，也不要未落盘新目录就空改旧稿。

## 输入

- 对话中的修改说明；用户 **@** 的上一版产出目录或其中文件。
- 交底目录：沿用上一版 `application_plan.yaml` 的 `case_dir`；没有则问一次。
- 点名补图：只处理用户指定的路径，见 `figures.md`「点名图」。

## 输出

新时间戳目录 + 该目录内四件套 Word + `问题清单.md` + 本目录 `申请文件修订对话记录.md`。旧目录保留。

用户明确要求覆盖某路径时从其意。
