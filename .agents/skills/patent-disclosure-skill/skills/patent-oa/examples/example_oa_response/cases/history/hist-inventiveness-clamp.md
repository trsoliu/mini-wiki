# 【示例】卡扣限位结构创造性答复（脱敏）

## 通知书要点

审查员认为权利要求1相对于对比文件1与公知常识的结合不具备创造性：区别仅在于卡扣端部增加限位凸起，属于常规结构替换。

## 策略

保留独立权利要求主体；将说明书记载的「限位凸起 + 导向斜面」一并写入权利要求1；意见陈述强调二者配合解决装配偏斜卡滞。

## 陈述要点

1. 对比文件1仅公开弹性卡扣，未公开限位凸起与导向斜面的组合。  
2. 二者功能相互支持，非简单叠加。  
3. 修改特征来自原说明书（示例：待指认段落）。

## 修改摘要

权利要求1增加「限位凸起与导向斜面配合」；说明书适应性修改。

## 结果

修改后授权。
