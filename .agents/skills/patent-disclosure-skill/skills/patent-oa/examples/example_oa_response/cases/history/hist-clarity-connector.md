# 【示例】连接器接口清楚性答复（脱敏）

## 通知书要点

审查员认为权利要求1中「可适配接口」含义不清楚，导致保护范围无法确定。

## 策略

不修改权利要求；在意见陈述中结合说明书实施例解释「可适配接口」指具备限位凹槽与弹性触点的插接结构，并指向附图标记。

## 陈述要点

1. 说明书已给出结构限定与附图标记对应关系。  
2. 本领域技术人员结合实施例可以清楚理解。  
3. 无需为清楚性单独缩小范围。

## 修改摘要

无修改。

## 结果

意见陈述后授权。
