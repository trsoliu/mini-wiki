# 【示例】某装置创造性答复（脱敏）

## 通知书要点

审查员认为权利要求1相对于对比文件1与公知常识的结合不具备创造性，认为区别技术特征仅为常规结构替换。

## 策略

保留独立权利要求主体；将说明书中记载的「限位配合 + 导向斜面」组合特征并入权利要求1；意见陈述中强调该组合解决的装配误差与卡滞问题及预料不到的效果。

## 陈述要点

1. 确认对比文件1未公开导向斜面与限位面的同时限定。  
2. 说明二者功能上相互支持，非简单叠加。  
3. 指出修改特征来自原说明书第×段（示例中用「待指认段落」代替真实页码）。

## 修改摘要

权利要求1增加特征：……（脱敏）；说明书适应性修改对应段落。

## 结果

修改后授权。
