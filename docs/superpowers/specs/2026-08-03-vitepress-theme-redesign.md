# Mini-Wiki VitePress 风格主题重构设计

## 背景

Mini-Wiki 当前站点已经具备中英双语文档、搜索、主题切换和 AI 发现产物，但视觉语言偏向实验性产品海报：超大标题、全局网格背景、复杂知识图和较重阴影削弱了文档阅读体验。与此同时，顶部导航与左侧导航重复列出同一组文档页面，造成信息架构冗余。

本次重构采用用户确认的方案 A：以 [VitePress 官方站](https://vitepress.dev/) 为参照，重做首页和文档主题，让界面回归克制、稳定、内容优先的文档产品风格。

## 目标

1. 建立接近 VitePress 的清爽文档视觉：纯色内容面、明确排版、细边框、轻量圆角和单一品牌色。
2. 消除顶部导航与左侧导航的页面重复。
3. 将首页收敛为简洁 Hero、安装入口和功能卡片，不再承担完整产品手册职责。
4. 保留中英双语、站内搜索、深浅主题、移动端导航、AI 产物和 GitHub Pages 发布能力。
5. 保持无障碍键盘焦点、减少动画偏好和 375px 移动端无横向溢出。

## 非目标

- 不修改 Mini-Wiki CLI、知识网络模型或文档事实。
- 不增加新的产品功能、文档路由或第三方运行时依赖。
- 不改变 Silen 构建、AI audit、AI eval、产物契约或 Pages 部署路径。
- 不逐像素复制 VitePress 品牌；只复用其信息层级、节奏和文档站设计原则。

## 信息架构

### 顶部导航

顶部只承担全局操作，不再枚举文档页面：

- Mini-Wiki Logo 与标题：返回当前语言首页。
- 版本 `v3.3.0`：链接到 GitHub Release。
- GitHub：继续使用 Silen social link。
- 搜索、语言切换、深浅主题：保留 Silen 原生能力。

顶部 `nav` 中不得出现 `/guide/`、`/knowledge-network/`、`/features/`、`/security/`、`/reference/` 或对应英文路由。

### 左侧导航

左侧导航独占文档目录，并按阅读任务重组：

- 开始使用 / Get started
  - 五分钟上手 / Five-minute guide
- 核心概念 / Core concepts
  - 知识网络 / Knowledge network
  - 核心能力 / Core features
- 运维与参考 / Operations and reference
  - 安全边界 / Security boundaries
  - 命令与配置 / CLI and configuration

首页不显示左侧导航。移动端抽屉复用同一份 sidebar 数据，不维护第二份目录。

## 视觉方向

### 基础风格

- 背景使用纯白与近黑色面，不使用全局网格、噪点或大面积装饰纹理。
- 品牌色采用接近 VitePress 气质的蓝紫色；交互状态通过同一色相的深浅变化表达。
- 正文使用系统无衬线字体栈，优先保证中英文混排清晰、加载稳定和平台原生感。
- 阴影仅用于浮层和首页视觉标记；普通卡片、代码块和导航主要依靠细边框分层。
- 圆角控制在 6 至 12 像素，避免胶囊化和营销页式大圆角。

### 顶部栏

- 高度保持约 64 像素，使用半透明背景与轻微模糊，底部为 1 像素分隔线。
- Logo、标题和右侧控制保持紧凑；桌面端不再出现五个重复页面入口。
- 当前版本呈现为低强调度文字入口，不与主要操作竞争。

### 首页

首页使用 VitePress 式两栏 Hero：

- 左栏依次呈现产品名、核心主张、简短说明、主次按钮和安装命令。
- 主按钮为“开始使用”，次按钮为“在 GitHub 查看”。
- 右栏使用本地 Logo 和低饱和蓝紫光晕形成简洁视觉锚点，不再渲染复杂知识图节点与连线。
- Hero 标题在桌面端约 56 至 64 像素，在移动端约 40 像素，不再使用超过 100 像素的海报字号。

Hero 下方使用 3 列、移动端 1 列的功能卡片：

1. 确定性构建 / Deterministic builds
2. 源码可追溯 / Source traceability
3. 中英混合搜索 / CJK-aware search
4. Bases 与 Canvas / Bases and Canvas
5. 安全协作边界 / Safe collaboration
6. 面向 AI Agent / Agent-ready output

每张卡片仅包含小型图标、标题和两行左右说明。现有更深的工作流、边界和命令内容继续由文档页面承载。首页底部保留 AI 产物入口，但改为紧凑链接条。

### 文档页面

- 主内容宽度约 688 至 720 像素，正文行高约 1.75。
- 一级标题约 32 至 36 像素，二级标题使用留白分节，不再使用虚线顶边。
- 左侧栏宽度约 272 像素，当前项使用浅品牌色底和品牌色文字。
- 右侧目录保持轻量，仅显示标题、细竖线和当前阅读位置。
- 代码块使用 8 像素左右圆角、低对比边框，不使用明显悬浮阴影。
- 提示块沿用语义化组件，但改成 VitePress 风格的柔和底色和左侧品牌色边线。

### 深色主题

深色主题使用近黑蓝背景、较低亮度边框和适度提高的正文对比度。品牌色在深色背景中提高亮度，但不使用霓虹光效。所有状态仍通过语义变量控制，不在组件中硬编码颜色。

### 动效

只保留 150 至 200 毫秒的颜色、边框和轻微位移动效。首页允许一次轻量淡入，不使用循环动画。`prefers-reduced-motion: reduce` 下动画和过渡应接近零时长。

## 实现边界

预计只修改以下生产文件：

- `site/.silen/config.ts`：拆分顶部全局入口与左侧文档目录。
- `site/.silen/custom.css`：替换当前实验性主题为 VitePress 风格设计系统。
- `site/index.mdx` 与 `site/en/index.mdx`：重构双语首页结构。
- 必要时小幅调整 `site/.silen/theme.tsx`，但继续扩展 Silen DefaultTheme。

测试修改集中在 `tests/test_site_contract.py`，不改变已有 AI 评测内容和公共文档事实。

## 测试与验收

### 自动化契约

- 顶部导航只包含版本等全局入口，不包含五个文档路由。
- 中英文 sidebar 各自完整且只出现一次五个文档路由。
- 首页不再包含知识图节点、全局网格主题或旧海报级标题样式。
- 中英文首页都包含产品主张、安装命令、两个 CTA、六项功能卡片和四个 AI 产物入口。
- 语义主题变量、焦点样式和减少动画规则继续存在。
- Silen build、AI audit、AI eval、产物契约、Python 测试、Ruff 和 Mypy 全部通过。

### 浏览器验收

- 1440px 桌面端：首页信息密度接近 VitePress，顶部没有页面级重复导航。
- 文档页：左侧只显示分组目录，顶部只显示全局入口，右侧目录正常。
- 375px 移动端：无横向溢出，Hero 按钮与功能卡片单列显示，移动导航可打开和关闭。
- 中文与英文路由、语言切换、搜索、深色模式、键盘焦点和 404 页面正常。
- 正常页面控制台无 error 或 warning；线上 Pages 路由和 AI 产物返回预期状态。

## 发布与回滚

完成本地和浏览器验收后直接提交到已授权的 `main`，由现有 Pages 工作流发布。若线上视觉或导航验收失败，通过后续修复提交回滚具体主题改动，不切回旧的 legacy Pages 发布方式。
